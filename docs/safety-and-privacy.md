# Safety and Privacy

This project is a static client-side prototype. It has no server-side processing, no authentication, and no database.

No real patient data, identifiers, images, screenshots, exported reports, or case examples should be committed to this repository.

If a photo field or similar input is present, it is intended only for local/session use if implemented that way. Browser and local storage behavior must be manually validated before any institutional use.

Institutional consent, KVKK compliance, data governance review, and information security review remain the responsibility of the user and institution.

This prototype is not for routine clinical use without expert review, local validation, and appropriate governance.

# Deployment

## GitHub Pages

1. Create a GitHub repository.
2. Add the repository files.
3. Push the files to GitHub.
4. Open GitHub repository settings.
5. Go to **Settings -> Pages**.
6. Set **Source** to **Deploy from branch**.
7. Set **Branch** to `main`.
8. Set **Folder** to `root /`.
9. Save the configuration.

Expected URL:

```text
https://<username>.github.io/<repo-name>/
```

GitHub Pages may take a few minutes to deploy after the first configuration or after updates.

Do not upload real patient data. Do not upload patient screenshots, patient images, exported reports, identifiers, or real case examples.
